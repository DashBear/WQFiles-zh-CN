# WQFiles-zh-CN

WQ Files 0.7（build 26）的非官方简体中文汉化补丁。包含 **481 条译文**，使用 Python 标准库从原始 IPA 生成待重新签名的汉化安装包。

**在 iPhone 13 pro IOS27.0.1 上安装运行**。原始应用、作者信息和相关权利归原作者所有；本仓库只提供汉化脚本与译文，不附带原始 IPA。

# 原仓库地址：https://github.com/kolbicz/WQFiles

本仓库只采用chatgpt进行汉化，未做其他任何更改。


## 汉化范围

- 主界面、容器分类与路径跳转
- 文件浏览、导入、分享、重命名与删除
- 应用数据备份、恢复与清空
- 缓存清理与崩溃日志操作
- 属性列表编辑器、文本编辑和十六进制查看器
- 主要状态提示、确认对话框及错误信息

部分诊断日志、系统应用名称、技术标识符和作者信息保留英文。此补丁直接替换编译后的文案，生成的应用固定使用这些中文文案，不提供应用内中英文切换。

## 使用方法

需要 Python 3.10 或以上，无需安装第三方依赖。

```powershell
git clone https://github.com/DashBear/WQFiles-zh-CN.git
cd WQFiles-zh-CN
python localize.py "F:/download/WQFiles.ipa"
```

也可以指定输出位置：

```powershell
python localize.py "F:/download/WQFiles.ipa" -o "dist/WQFiles_zh-CN.ipa"
```

脚本生成三个文件：

- `.ipa`：汉化后的待重签名安装包
- `.csv`：英文与简体中文对照表
- `.validation.json`：输入输出哈希、文案数量及静态验证结果

原始文件不会被覆盖。若输出文件已存在，请选择新路径或自行移走旧文件。

## 签名与安装

修改应用内容会使原签名失效。**安装前必须重新签名，并保留 App Group entitlement（应用组权限）**；否则原应用的跨容器访问功能可能无法使用。

包中保留原签名元数据供签名工具读取，不代表原签名仍有效。脚本不提供签名证书、描述文件，也不执行签名或安装。系统版本和各项功能限制继承自原应用；最低系统版本不代表所有功能都可用。

## 实现与校验

原包没有独立的本地化文案资源，界面使用编译后的 Objective-C `CFString` 常量。脚本将译文编码为 UTF-16，写入该版本现有、已映射且经检查全为零的填充区域，更新相应常量的编码标志、字符数及字符串指针。

指针按 `DYLD_CHAINED_PTR_64_OFFSET` 处理，只替换目标偏移，保留链信息。程序机器指令、Mach-O 加载命令、文件偏移及虚拟地址布局保持不变。桌面显示名改为“WQ 文件”，并声明简体中文本地化。

构建时执行以下校验：

1. 原始 IPA 的 SHA-256 必须完全匹配。
2. 每条译文必须匹配原文，格式占位符及顺序必须一致。
3. 译文必须放入可用填充区，不允许溢出。
4. 全部 1,267 个 CFString 重新解码核对；未翻译的常量保持原文。
5. 检查链指针元数据、机器指令及加载命令未改变。
6. 回读输出 IPA 并检查 ZIP 完整性。

静态校验不能替代实机测试。签名工具兼容性、界面布局和实际读写功能尚未验证。欢迎反馈系统版本、签名工具和具体页面，帮助完成验证。

## 修改译文

编辑 `translations/zh-Hans.json` 中的 `translation`。保留 `index`、`source` 以及 `%@`、`%lu`、`%lld` 等占位符的类型和顺序。请勿用此翻译表处理其他版本的应用。
